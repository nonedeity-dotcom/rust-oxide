# Island Survival

Выживание от первого лица на острове (3 биома, дорога с бочками, добыча, крафт, печь). three.js + Vite, упаковка в APK через Capacitor.

## Запуск
```
npm install
npm run dev      # http://localhost:5173 (с телефона: адрес из консоли, --host уже включён)
npm test         # тесты логики (без three.js)
```

## Управление
| Телефон | ПК |
|---|---|
| левая половина экрана — джойстик (до упора = бег) | WASD, Shift — бег, Space — прыжок |
| правая половина — камера | мышь (клик по экрану захватывает курсор) |
| ⛏ — удар / использовать, ⤒ — прыжок, 🎒 — инвентарь | ЛКМ или E — удар, Tab / I — инвентарь, 1–6 или колесо — хотбар |

- Удар по дереву/камню/руде/бочке добывает ресурс. Тип инструмента важен (топор — дерево, кирка — камень/руды).
- Печь: скрафти (камень 200 + дерево 50), выбери в хотбаре, ⛏ — поставить. Удар по печи открывает её: загрузи руду и дерево (топливо), заберёшь металл и серу.
- Инвентарь: тап по слоту, затем тап по другому — поменять местами / слить стаки.

## APK
Вариант 1 (автоматически): залей репозиторий на GitHub — workflow `.github/workflows/android.yml` соберёт `app-debug.apk` (вкладка Actions → Artifacts).

Вариант 2 (локально, нужен Android Studio):
```
npm run cap:add && npm run cap:sync && npm run cap:open
```
В `AndroidManifest.xml` добавь к `<activity>` атрибут `android:screenOrientation="sensorLandscape"`.

## Структура
- `js/data.js` — предметы, рецепты, инвентарь, печь (чистая логика)
- `js/terrain.js` — рельеф, биомы, дорога, расстановка объектов
- `js/trees.js` — деревья из `models/*.obj` (генерируется `python3 tools/convert_trees.py`)
- `js/models.js`, `js/world.js`, `js/main.js` — 3D, мир, игрок и интерфейс
