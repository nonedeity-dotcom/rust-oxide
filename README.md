# Xust

Выживание от первого лица на острове (3 биома, дорога с бочками и заправками, добыча, крафт, печь, животные, бой). three.js + Vite, упаковка в APK через Capacitor.

## Запуск
```
npm install
npm run dev      # http://localhost:5173 (с телефона: адрес из консоли, --host уже включён)
npm test         # тесты логики (без three.js)
```

## Управление
| Телефон | ПК |
|---|---|
| левая половина экрана — джойстик (до упора = бег) | WASD, Shift — бег, Space — прыжок, C / Ctrl — присесть |
| правая половина — камера | мышь (клик по экрану захватывает курсор) |
| ⛏ — удар / использовать, ⤒ — прыжок, ⤓ — присесть, 🎒 — инвентарь | ЛКМ или E — удар, Tab / I — инвентарь, 1–6 или колесо — хотбар |
| ☰ — меню: Настройки, Карта, Суицид, Продолжить | Esc — меню, M — карта |

Настройки (громкость, качество графики, чувствительность, угол обзора, размер кнопок, джойстик, инверсия) сохраняются на устройстве.
Качество: «Низкая» — без теней и с короткой травой (для слабых телефонов), «Средняя» — по умолчанию, «Высокая» — тени 2048 и густая дальняя трава.
«Суицид» возрождает на берегу со стартовым инвентарём (нужно нажать дважды). Все звуки синтезируются в игре, отдельных файлов нет.

- Удар по дереву/камню/руде/бочке добывает ресурс. Тип инструмента важен (топор — дерево, кирка — камень/руды).
- Печь: скрафти (камень 200 + дерево 50), выбери в хотбаре, ⛏ — поставить. Удар по печи открывает её: загрузи руду и дерево (топливо), заберёшь металл и серу.
- Инвентарь: тап по слоту, затем тап по другому — поменять местами / слить стаки.

## Животные и охота
| Зверь | Где живёт | Поведение | Здоровье | Укус |
|---|---|---|---|---|
| 🦌 Олень | лес, снег | замечает с 12 м и убегает (бегущий игрок догоняет) | 80 | нет |
| 🐗 Кабан | лес, пустыня | мирный, пока не ударишь; потом гонится 14 с | 110 | 14 |
| 🐻 Медведь | снег, лес | замечает с 16 м и гонится; от него можно убежать бегом | 300 | 30 |

- Крадущегося игрока замечают вдвое хуже (присесть: ⤓ / C / Ctrl).
- Бить можно чем угодно, но оружие сильно разное: кулак 4 · камень 7 · факел 8 · кирка 12 · топор 18 · костяной нож 16 (бьёт чаще) · **костяная дубинка 30**.
- Убитый зверь остаётся тушей на 4 минуты: бей по туше, пока не снимешь всё — **кости 🦴, ткань 🧵, кожа 🟫, жир 🧈**. Нож снимает быстрее всех и даёт +30%. Медведь даёт больше всех, олень меньше всех. Через 5–7 минут после исчезновения туши зверь появляется снова в другом месте.
- Здоровье 100: если 8 секунд не получать урон, оно восстанавливается (2 ед/с). Погибнешь — возродишься на берегу (или у спального мешка) с пустым инвентарём.

## Крафт из добычи
| Предмет | Рецепт | Зачем |
|---|---|---|
| 🔪 Костяной нож | 30 костей | быстрая разделка (+30% добычи), бьёт часто |
| 🏏 Костяная дубинка | 40 костей | лучшее оружие |
| 🦺 Костяная броня | 50 костей + 30 ткани | −50% урона; надеть: окно инвентаря → «Экипировка» (или выбрать в хотбаре и ⛏) |
| 🛏️ Спальный мешок | 30 ткани | выбрать в хотбаре, ⛏ — поставить; после смерти возродишься возле него (мешок один: новый заменяет старый) |

Кожа и жир пока ни во что не крафтятся — просто копятся.

## Заправки
На кольцевой дороге стоят 4 заправки (на карте — значок ⛽). На каждой два **ящика**: ⛏ / E по ящику — забрать всё содержимое. Выпадает: металл (чаще всего), плавленый металл ⚙️ (реже), костяной нож (редко). Что не влезло в инвентарь — остаётся в ящике. Опустевший ящик наполняется заново через 10 минут.

## APK
Залейте репозиторий на GitHub (ветка `main`): workflow `.github/workflows/android.yml` соберёт `Xust.apk` и выложит его в **Releases** — скачивается сразу как apk, распаковывать не нужно. Значок берётся из `icon.png`.

Локально (нужен Android Studio): `npm run cap:add && npm run cap:sync && npm run cap:open`, затем `python3 tools/make_icons.py` для значка.

## Структура
- `js/data.js` — предметы, рецепты, инвентарь, печь, оружие, здоровье и броня, животные, лут ящиков (чистая логика)
- `js/terrain.js` — рельеф, биомы, дорога, расстановка объектов, заправки, точки обитания животных
- `js/station.js` — раскладка заправки (общая для генерации и модели)
- `js/fauna.js` — ИИ животных (чистая логика), `js/animals.js` — модели зверей (генерируется `python3 tools/convert_animals.py` из `models/*_lowpoly.obj`)
- `js/trees.js` — деревья из `models/*.obj` (генерируется `python3 tools/convert_trees.py`)
- `js/models.js`, `js/world.js`, `js/main.js` — 3D, мир, игрок и интерфейс
- `js/grass.js`, `js/grassdata.js` — трава (чанки вокруг игрока, ветер), `js/world.js` — ещё и тени, небо, вода
- `js/audio.js` — звуки и окружение, `js/settings.js` — настройки, `js/map.js` — карта
- `tools/make_icons.py` — значки Android из `icon.png`
